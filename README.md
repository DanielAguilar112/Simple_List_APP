Project Overview
This is a functional React-based list application designed to manage tasks across multiple categories. It features a modern dark-mode interface and advanced list manipulation tools.

------------------------------------------------------------------------------------------------------------------------------------------------------
 
Features Implemented
Create Simple List App: Initialized with dummy data across three categories to demonstrate functionality immediately.

Add/Remove: Users can add new entries via the text input and remove them using the trash icon button.

Join/Split Advanced Features: * Join: Select multiple items using checkboxes to merge them into a single entry connected by " & ".

Split: Select a merged item to break it back down into individual list entries.

Tabs for Multiple Lists: Added a tabbed navigation bar at the top to switch between "Personal," "Work," and "Groceries" lists.

------------------------------------------------------------------------------------------------------------------------------------------------------
 
How to Run the App
Extract the zip file (excluding node_modules).

Open your terminal in the project folder.

Install dependencies:

Bash
npm install
Launch the development server:

Bash
npm run dev
Open your browser to the URL provided in the terminal (mine was  http://localhost:5173).

Mobile testing: Run `npm run dev -- --host` and access the Network URL on a mobile browser.
